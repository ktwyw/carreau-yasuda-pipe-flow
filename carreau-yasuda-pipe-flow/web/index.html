The Python package in this repository evaluates the closed-form hypergeometric expressions of the paper (Eqs. 18, 23, 31) with SciPy. This page has no special-function library, so it integrates Eqs. (17) and (26) directly with composite 5-point Gauss–Legendre quadrature on 400 panels graded toward the tube axis; the two agree to about nine significant figures, well beyond what any plot can show. The wall shear rate, Eq. (4), is found by bisection in log γ̇. Source code, Python package and scripts: github.com/ktwyw/carreau-yasuda-pipe-flow (MIT License).
